## ✨ Features
- **Utility-First Design:** Built entirely using Tailwind CSS utilities for rapid and maintainable styling.
- **Modern UI Components:** Hero section, feature grids, testimonial sliders, and newsletter subscription form.
- **Mobile-First Layout:** 100% responsive across mobile, tablet, and widescreen displays.
- **Clean Structure:** Well-commented, semantic HTML code.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic document markup
- **Tailwind CSS:** Utility-first CSS framework
- **CSS3:** Custom layout enhancements
